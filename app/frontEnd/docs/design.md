# AirPulse 设计规范 · 第三版

> 改 token 先改这里，再改 `src/index.css`。

## 0. 这一版推翻了什么

上一版的问题：

- **装饰堆砌**：渐变字、径向光晕、点阵底纹、毛玻璃、登录页极光——全是和数据无关的东西，让读数和背景糊在一起，是「AI 味」的主要来源。
- **形式大于信息**：表盘、点阵内存、CPU 核心柱这类「仪器感」组件，大多只是装饰。
- **版式模板化**：每块面板都是「左上标题 + 右上一句说明」，说明文字又多又空。
- **细节不严谨**：数字角标没有光学居中，间距没有统一步长，对齐靠目测。
- **动效不顺**：切页时整页模糊并等上一页退场；邻区每 2.5 秒按信号重排一次，列表来回跳。

## 1. 向谁学、学什么

| 参考 | 学到的具体做法 | 用在哪 |
|---|---|---|
| Apple 天气 | 模块 = 小标签 + 大读数 + 一句人话 + 一个极简可视化（紫外线色阶条上的一个点） | 总览模块、信号与温度色阶条 |
| Apple 股票 / 健康 | 迷你走势只在需要看趋势时出现；先给结论，数字是证据 | 网速走势、流量预测 |
| iOS 设置 | 分组列表：标签在左，值或控件在右；说明放在分组底部的脚注里 | 选网模式、设置页 |
| iOS 标签栏 / 角标 | 红底白字角标，圆形或胶囊，压在图标右上角，并描一圈背景色把它和图标分开 | 移动端底部导航、侧边栏计数 |
| Flighty（Apple 设计奖） | 信息密度高但层次分明：状态色只用在状态上，数字和时间排版讲究 | 小区列表、读数排版 |
| Linear | 侧边栏的精度（图标 18、正文 14、计数右对齐、行高 36）；动画短而快（≤ 200 ms） | 桌面侧边栏、所有过渡 |
| Things 3 | 安静：大量留白、少色，只在完成某个动作时给一点细小的动效 | 整体气质 |

## 2. 原则

1. **先回答用户的问题**：网好不好、有多快、流量用了多少、有没有新短信（验证码）、机器热不热。总览用「一句话 + 一个数字」逐条回答。
2. **数字是主角，装饰为零**：不用渐变字、光晕、毛玻璃、点阵、极光。可视化只在传达信息时出现。
3. **一屏一个焦点**：每页只有一个最大的数字。
4. **说明文字要少**：标签能说清楚的不加说明，必要的说明放到分组脚注里。
5. **实时但不躁动**：数字逐位滚动，只动变化的那一位；列表用粘滞排序，信号明显变强才换位；曲线按时间平滑地滚动。
6. **动作就近、反馈即时、危险才确认**。

## 3. Token

### 3.1 颜色（Apple 系统色体系）

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#F5F5F7` | `#000000` | 页面底色 |
| surface | `#FFFFFF` | `#1C1C1E` | 卡片 |
| raised | `#FFFFFF` | `#2C2C2E` | 浮层、深色下卡片里的卡片 |
| sunken | `#F2F2F7` | `#2C2C2E` | 卡片里的凹陷区：输入框、轨道、分段控件 |
| line | `rgb(60 60 67 / .12)` | `rgb(255 255 255 / .08)` | 发丝分隔线 |
| text / 2 / 3 / 4 | `#1D1D1F` `#6E6E73` `#86868B` `#AEAEB2` | `#F5F5F7` `#A1A1A6` `#7C7C80` `#545458` | 主 / 次 / 说明 / 占位 |
| accent | `#007AFF` | `#0A84FF` | 交互色：按钮、选中、链接 |
| success / warning / danger | `#34C759` `#FF9500` `#FF3B30` | `#30D158` `#FF9F0A` `#FF453A` | 只表示状态，永远配文字或图标 |
| series-down / up | `#007AFF` / `#FF9500` | `#0A84FF` / `#FF9F0A` | 下行永远蓝、上行永远橙 |

可选强调色：蓝（默认）、青、紫、粉、石墨，只影响交互色，不影响状态色与数据色。

### 3.2 字体与字号

系统字体优先（SF Pro + 苹方），其他平台用本地打包的 Inter + 系统中文黑体。所有数字等宽（`tabular-nums`）。

| 层级 | px / 行高 / 字重 | 用途 |
|---|---|---|
| display | 64 / 64 / 600，字距 -0.035em | 每页唯一的主数字 |
| title | 28 / 34 / 700 | 页面标题 |
| metric | 28 / 32 / 600 | 模块读数 |
| headline | 15 / 20 / 600 | 卡片标题、列表主文字 |
| body | 15 / 22 / 400 | 正文 |
| footnote | 13 / 18 / 400 | 次要文字、模块说明句 |
| caption | 12 / 16 / 500 | 标签 |
| caption2 | 11 / 13 / 600 | 角标、坐标轴 |

单位跟在数字后面：字号约为数字的一半，颜色退到 text-2。

### 3.3 间距、圆角、阴影

- 4 的倍数。卡片内边距 20（手机 16），卡片间距 16（手机 12），页面边距 32（手机 16）。
- 圆角：卡片 20、卡片内的块 14、控件 12、芯片 10、胶囊全圆。
- 浅色卡片不描边，只有一层极轻的投影 `0 1px 2px rgb(0 0 0 / .04)`；深色卡片不加投影，靠底色区分层次。

### 3.4 角标

- 计数角标：高 18、最小宽 18、左右内边距 5、11px/600、等宽数字；文字用 `text-box: trim-both cap alphabetic` 做光学居中（不支持的浏览器用行高兜底）。
- 未读用红底白字；中性计数（在线设备数）用灰底灰字。
- 超过 99 显示 `99+`；数字变化时轻轻弹一下，出现和消失时缩放淡入淡出。
- 压在图标上时描一圈 2px 的背景色。

### 3.5 动效

- 时长：快 120 ms、常规 200 ms、慢 320 ms；缓动统一用 `cubic-bezier(.22, 1, .36, 1)`（快进慢停）。
- 切页：新页面直接出现，内容淡入并上移 6px，用时 180 ms；不模糊，也不等旧页面退场。
- 按压：缩到 0.97，松手后弹回。
- 数字：逐位滚动，只动变化的那一位。
- 列表：粘滞排序，换位时 280 ms 平滑移动。
- 开启「减弱动态效果」时，去掉所有位移和缩放，只保留透明度变化。

## 4. 布局

- **桌面（≥ 1024）**：左侧固定侧边栏 240（品牌、设备状态、导航、设置），内容最大宽 1120，居中。
- **手机 / 平板（< 1024）**：顶部大标题 + 底部标签栏（总览、射频、热点、短信、更多）。

## 5. 页面

- **总览**：标题是运营商，副标题是「制式 · 频段 · 联网时长」 → 实时网速（主数字 + 走势）+ 信号模块 → 快捷开关（移动数据、Wi-Fi、性能模式、IPv6、网络模式；平铺小块，开着的图标点亮成强调色，行为与设置页的开关一致）→ 四个模块（本月流量、在线设备、最新短信、机身温度）→ 当前小区 + 供电与负载 → 设备信息。
- **射频**：选网模式（iOS 式单选列表）+ 频段锁（按低 / 中 / 高频分组的芯片，有改动时底部出现「还原 / 应用」）→ 周边小区（粘滞排序，点一行打开详情，在详情里锁定）。
- **设置**：iOS 式分组列表。
- **登录**：居中的应用图标 + 一组合并的输入框 + 主按钮，纯色背景。
